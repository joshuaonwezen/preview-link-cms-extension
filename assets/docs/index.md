# Share preview

## Setup
1. **Site**: the site URL that renders `/preview/share` for this CMS instance, and that site's
   `OPTIMIZELY_PREVIEW_SECRET`.
2. **CMS API client**: a client ID and secret from CMS → Settings → API Keys, used to read the open
   item's versions.

## Using it
Open a page or experience and open the **Share preview** tab on the right-hand rail.

- **This version** is the version open in the editor. Switch variation in the editor and the link
  follows.
- **Newest version of each variation** links the latest version of the original page and of every
  variation.

Links show exactly one version and don't change when the page is edited later. Share a new link after
editing. Images and folders can't be shared: the site only renders pages.
